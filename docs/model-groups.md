# 模型账号分组

分组只是账号的集合，不声明、不限制能力，允许文字、图片、视觉等不同能力的账号混合加入。具体能力和模型由账号提供。账号分组用于把多个标准 API 账号分配给工具，与前台的工具分类独立。参考 sub2api 的账号与分组多对多关系，一个账号可以加入多个分组；本功能不管理上游网页登录会话。

## 配置流程

1. 超级管理员在「模型账号」填写 Base URL 和 API Key，点击「获取模型列表」后选择默认模型，也可手动填写。选择账号实际提供的能力：文字生成、图片生成、图片编辑、图片理解。「按能力指定模型」为可选项，可以使用同一个 Key 下不同的模型；未指定时使用默认模型。
2. 在「账号分组」创建分组，填写名称并加入账号，使用上移／下移调整优先顺序。允许先保存空分组，但没有匹配的启用账号时不能执行请求。
3. 在「工具管理 → 编辑工具 → 模型调用分组」选择工具所需能力和任意分组。分组不会因能力被隐藏或拒绝绑定。文字工具的能力固定为文字生成。普通管理员可以选择分组，但不能读取账号密钥、修改账号或管理分组。
4. 「使用记录」显示最后实际调用的账号、分组和尝试次数；「模型账号」显示冷却状态，超级管理员可以手动重置冷却。

账号能力由管理员声明，模型列表连通检查不能证明生图、编辑或视觉接口可用。图像工作台已支持参考图上传、图片生成和图片编辑调用，执行与限制见 [图片工具](image-tools.md)；其他图片工具以实际开放状态为准。

## API Key 接入

参考本地 sub2api `frontend/src/components/account/CreateAccountModal.vue` 中的 API Key 服务地址、密钥及模型配置形式，采用当前项目实际支持的 OpenAI 兼容接口。没有加入未实现的其他原生协议或 OAuth 登录方式。

- 获取模型列表通过服务端 GET `{base_url}/models` 完成，密钥不会回传给浏览器。新增账号可在保存前获取；编辑时可复用已保存密钥，留空表示保留。
- 请求最多 15 秒，响应上限 512 KiB，最多返回 1000 个合法模型 ID；失败仅显示可操作提示，可继续手动填写模型。
- 获取列表不会自动覆盖已填写的模型，不会自动推断能力，也不会发起生成请求。
- 默认模型和能力模型均由后台维护；文字执行和组内切换都读取当前账号的文字模型，后台使用记录保存实际调用的模型。

## 调度规则

- 已绑定分组优先于系统中的单账号覆盖和默认账号。分组被停用、为空或没有匹配账号时直接返回通用不可用提示，不跨组、不回退到环境密钥。
- 未绑定分组的工具保持原有单账号／环境配置方式。文字执行仅选择具有文字能力的账号。
- 从高到低选择匹配工具能力、启用且不在冷却期的账号。每次实际尝试前重新检查账号、成员关系和分组状态。
- 每次最多调用 3 个不同账号；单次调用最多 30 秒，整个组内尝试过程最多 95 秒，低于生成任务 120 秒的过期时间。不对同一个账号循环重试。
- 鉴权错误（401/403）或模型不存在（404）冷却 300 秒；限流（429）冷却至少 60 秒，数字 `Retry-After` 最多采用 300 秒；上游 5xx、连接异常或超时冷却 30 秒。
- 其他请求拒绝、内容拒绝、截断或不完整结果不触发账号切换。只记录受控错误代码，不保存或转发上游响应正文、密钥和用户输入。
- 冷却状态存储在 PostgreSQL，跨分组、跨进程共享。冷却到期后账号重新参与调度。修改密钥／模型／地址或手动重置会清除冷却并使旧版本请求的健康更新失效；成功请求不清除其他并发请求设置的冷却。
- 一次用户任务只预扣一次积分。全部失败只退回一次积分；同一请求标识重复提交返回原任务结果，即使账号此时已经进入冷却，也不会重复请求上游。

## 管理与权限

- 分组支持创建、编辑、停用和删除。删除前必须解除全部工具绑定；删除分组不会删除模型账号。
- 修改分组和工具使用版本号检查，避免覆盖其他管理员的修改。
- 分组完整信息、账号维护和冷却重置仅限超级管理员；安全分组选项和工具绑定对普通管理员开放；匿名和普通用户均不能访问管理接口。
- 公共工具目录与生成结果不包含分组配置和内部故障详情。组内尝试信息只在后台使用记录提供。
