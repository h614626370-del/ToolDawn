# 首页风格与素材

用户选择的原方案 4、5、6、7、10 对应 `midnight`、`cream`、`olive`、`plum`、`library`。首页和工具目录右上角的“风格”入口可随时切换；`tooldawn-directory-style` Cookie 保存偏好，SSR 首屏读取同一偏好，无效值退回午夜暖灯。

## 结构

- `useDirectoryStyle.ts` 与 `directoryStyles.ts` 管理样式和配图映射。
- `StyleSwitcher.vue` 使用原生 popover，支持外部点击关闭、Escape 和键盘聚焦。
- `FeatureCarousel.vue` 展示服务端实际存在的工具；每 6.5 秒轮播，悬停、键盘操作、手动切换和隐藏标签页时暂停。系统减少动态效果时不自动播放。支持箭头、圆点、左右方向键。
- 午夜暖灯为山景搜索区与轮播分栏，桌面工具图册采用五张加六张的紧凑排列；奶油拼贴在纸纹上组合竖向卡片和横向图块；橄榄工作台为带分类说明的横排工具架；酒红夜色保留雨夜城市背景与错落图块；墨绿书房采用贯穿内容区的深绿侧栏、纸纹与分类图册。
- 轮播使用与当前工具对应的整幅场景照片，右侧文字使用 21px 圆角、20px 背景模糊和半透明底色。左右圆形箭头位于图片两侧，圆点居中，播放开关在右下角。小屏幕保留场景和靠右的文字面板。
- 奶油、酒红、书房的侧边推荐使用两张有实际配图的工具入口，并避免与该风格首张轮播重复。所有卡片都展示图片；可用性仍取自 API。
- 搜索、分类、收藏、工具状态与详情入口沿用现有 API 和业务组件。

## 图片

场景图和功能示意图通过用户授权的 API、imagegen CLI、`gpt-image-2` 模型生成。原图及完整提示词位于 `output/imagegen/theme-assets-v1/` 与 `output/imagegen/theme-assets-v2/`。没有将 API 密钥写入项目文件。

网页素材位于 `apps/web/public/images/directory/`。第一批为 5 张场景、11 张工具示意图及 5 张风格菜单缩略图；第二批新增 6 张对应文字工具的宽幅场景、4 张山景/纸纹/雨夜背景。全部使用 WebP。生成图片只承担装饰与用途示意，标题、状态、按钮和导航均为可访问的真实页面内容。

内置种子通用图片替换为新素材；后台设置的自定义图片继续优先。图片加载失败显示文本回退，状态以 API 为准。
