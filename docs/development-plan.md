# ToolDawn 开发规划

更新日期：2026-10-29。本文按当前代码整理功能与后续事项，不代表已完成生产部署或真实商户联调。

## 产品范围

ToolDawn 仅提供站内自有 AI 工具，不收录站外工具。首页负责搜索、分类、收藏和导航，操作在各工具工作台中完成。默认中文，支持英文和移动端。

公开目录、账户中心和图像工作台共享五套主题配色；后台使用独立的浅色与深色主题。产品与界面约定见 `PRODUCT.md`。

## 当前功能

| 模块 | 已有能力 | 说明 |
| --- | --- | --- |
| 工具目录 | 搜索、分类、精选、详情、收藏与上下架 | 收藏按账号保存在当前浏览器 |
| 身份与账户 | 邮箱验证码、密码登录、密码找回、头像、会话管理 | 超级管理员使用独立凭据规则 |
| 文字工具 | 润色、改写、摘要、邮件、翻译、生日祝福 | API 请求内执行，支持记录、积分扣退与幂等 |
| 图像工作台 | 文生图、图生图、透明背景、图片编辑、作品管理 | 独立 Worker 执行持久化任务 |
| 模型账号 | 能力与模型配置、分组、优先顺序、故障切换与冷却 | 密钥由服务端加密保存 |
| 积分支付 | 钱包、流水、充值订单、人工调整、五种支付供应商 | 仅经校验的支付回调确认入账，实际收款需商户联调 |
| 运营后台 | 工具分类、用户、公告、工单、使用记录、监控与审计 | 区分普通管理员和超级管理员权限 |

## 架构与代码入口

浏览器通过 Nuxt 的同域 API 转发访问 FastAPI。业务规则由 Python 后端维护，PostgreSQL 保存业务数据与图片任务，Redis 用于限流等功能。图片 Worker 与 API 共用业务模块、独立运行。

| 目录或文件 | 职责 |
| --- | --- |
| `apps/web/app/pages/` | 公开页面、账户中心与后台路由 |
| `apps/web/app/layouts/` | 目录、账户、后台及工作台布局 |
| `apps/web/app/composables/` | 会话、主题、目录筛选与文字工具交互 |
| `apps/web/app/features/image-studio/` | 图像工作台、画布、编辑器和任务轮询 |
| `apps/web/i18n/locales/` | 中英文文案 |
| `apps/web/server/api/` | 同域 API 转发 |
| `services/api/src/tooldawn/main.py` | API 初始化与路由注册 |
| `services/api/src/tooldawn/modules/` | 目录、身份、文字、图片、支付、公告和运营模块 |
| `services/api/src/tooldawn/image_worker.py` | 图片任务领取、模型调用与结果处理 |
| `services/api/migrations/` | Alembic 数据库迁移 |
| `services/api/tests/` | 单元与数据库集成测试 |

模块按需要拆分路由、请求结构、数据访问和模型，避免在入口集中业务逻辑。新增工具需要实现执行器和参数校验，仅新增目录记录不会产生可执行能力。

## 执行与数据边界

- 文字调用在 API 请求中执行；账号分组按能力与优先顺序选择候选账号，仅可重试错误触发组内切换。
- 图片任务通过 PostgreSQL 持久化，由 Worker 领取。已领取但中断的上游请求不自动重放，过期任务失败并退分。
- 用户请求携带幂等标识，积分变化使用事务、用户行锁和流水记录，避免重复扣退。
- 文字输入不保存原文；图片任务输入与参考图短期加密保存。图片结果目前存储在数据库，尚未接入私有对象存储。
- 使用记录、作品、头像和工单校验用户身份及所有权；管理操作由服务端校验角色。
- 实际服务器地址、个人路径和凭据不写入公开文档或版本控制。

## 开发与验证

本地 PostgreSQL 和 Redis 使用独立 WSL 实例，配置方式见 [本地基础服务](local-infra.md)。修改文档无需启动服务；代码修改按影响范围运行检查：

- 后端：在 `services/api` 执行 `uv run ruff check .`、`uv run ruff format --check .` 及相关 pytest 测试。
- 数据库：使用已迁移的专用测试库验证；`scripts/check_remote.py` 会执行迁移和种子导入，运行前确认连接目标。
- 前端：在 `apps/web` 执行 `npm run typecheck`、`npm run build`；界面改动检查桌面、移动端和中英文。
- 权限与计费：检查未登录、普通用户、管理员和超级管理员边界，以及并发、幂等、失败退分和跨用户隔离。

当前仓库已有 CI 配置；检查是否通过以实际运行结果为准，不以文档记录代替验证。
