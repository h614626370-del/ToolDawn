# ToolDawn

ToolDawn 是一个面向中英文用户的在线 AI 工具平台。通过搜索、分类和收藏找到需要的工具，在独立工作台中完成文字创作与图片生成。平台仅提供站内自有工具。

## 主要功能

- **文字工具**：文本润色、文案改写、长文摘要、邮件撰写、翻译和生日祝福。
- **图像工作台**：文生图、图生图、透明背景、图片编辑与作品管理。
- **账户中心**：个人资料、使用记录、积分钱包、充值、工单和账户安全。
- **管理后台**：工具与分类、用户、公告、模型账号与分组、订单和系统设置。
- **界面体验**：中英文切换、多套主题，适配桌面与移动端。

## 技术栈

- 前端：Nuxt、Vue、TypeScript、Tailwind CSS。
- 后端：Python、FastAPI、SQLAlchemy、Alembic。
- 数据与任务：PostgreSQL、Redis、独立图片任务 Worker。

项目持续开发中，模型调用与支付功能需配置相应服务。
