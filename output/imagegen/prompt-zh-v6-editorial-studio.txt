Use case: ui-mockup
Asset type: High fidelity desktop homepage design proposal for ToolDawn, a Chinese online AI tool directory. One complete coherent website screenshot, not a collage of alternatives.
Primary request: Redesign the whole visual language into a confident, beautifully art-directed creative tools studio. The old UI was a dark header, yellow search banner and rows of pastel tinted cards; the owner disliked that overall style. Create a distinctly new visual proposal, sophisticated and inviting, with excellent Chinese typography and colorful imagery rather than coating everything in pastel fills.
Composition: Straight-on 1536 x 1024 desktop webpage, edge-to-edge UI with no browser frame, no device mockup, no perspective. White/light neutral canvas, generous 80px page gutters, precise editorial grid. A compact but expressive introduction below: oversized black Chinese headline aligned left, one phrase emphasized in vivid cobalt blue. A large clean functional search input below the headline. The actual directory must start within the upper half of the image, not a giant marketing hero.
Visual language: Clean white, deep ink typography, electric cobalt #315CF5 primary accent, occasional fresh tangerine #F47B40 in images. Thin light-gray separators, crisp 12px corners, carefully balanced whitespace, subtle physical shadows only for preview objects. No black header, no warm yellow search banner, no rainbow pastel full-card backgrounds, no purple gradients. Professional crafted product design, expressive imagery, clear hierarchy and ample readable text, not a generic SaaS landing page.
